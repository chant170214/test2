# ShadowChat

Android anonymous 1:1 chat prototype that follows the provided specification. The project is structured using a layered architecture (presentation/domain/data) and includes placeholder implementations for Tor connectivity, cryptographic handshakes, and secure messaging.

## Repository contents

- `ShadowChat_download_url.txt` — data URL that serves a zipped copy of the project directly from the repository contents.

The zip archive is no longer stored separately; use the data URL to retrieve the packaged project if needed.
